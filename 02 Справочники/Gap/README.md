# Справочник Gap

## Назначение

Справочник типовых организационных разрывов CMOC.

Разрыв — это типовая потеря организационной способности, нарушающая организационный поток.

Разрывы являются объектами диагностики.

Каждый разрыв должен быть связан:

- с потоком (Flow);
- со способностью (Capability);
- с организационной сборкой (Assembly);
- с симптомами;
- с потерями.
