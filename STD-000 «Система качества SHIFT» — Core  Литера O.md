SHIFT-QMS v0.1 (Литера O)

| Код      | Объект                  | Назначение                                    |
| -------- | ----------------------- | --------------------------------------------- |
| **STD**  | Стандарты               | Определяют правила выполнения работ           |
| **OP**   | Операции                | Определяют технологию выполнения проходов     |
| **QA**   | Приёмка                 | Проверяет соответствие результата требованиям |
| **NC**   | Несоответствия          | Регистрируют отклонения                       |
| **CAPA** | Корректирующие действия | Устраняют причины несоответствий              |

---

## STD

|Код|Наименование|
|---|---|
|STD-001|Один проход — одна операция|
|STD-002|Один объект — одна строка Реестра|
|STD-003|Источник неизменяем|
|STD-004|Реестр только обогащается|
|STD-005|Проход завершается после обработки всех строк|

---

## OP

|Код|Наименование|
|---|---|
|OP-001|Извлечение терминов|
|OP-002|Извлечение различений|
|OP-003|Извлечение формулировок|
|OP-004|Классификация|
|OP-005|Построение связей|

---

## QA

|Код|Критерий|
|---|---|
|QA-001|Все строки обработаны|
|QA-002|Дубликаты отсутствуют|
|QA-003|Источник указан|
|QA-004|Формат Реестра соблюдён|
|QA-005|Результат воспроизводим|

---

## NC

|Код|Несоответствие|
|---|---|
|NC-001|Пропущена строка|
|NC-002|Обнаружен дубликат|
|NC-003|Отсутствует ссылка на Источник|
|NC-004|Нарушен формат Реестра|
|NC-005|Результат невоспроизводим|

---

## CAPA

|Код|Корректирующее действие|
|---|---|
|CAPA-001|Повторить проход|
|CAPA-002|Исправить Реестр|
|CAPA-003|Уточнить стандарт|
|CAPA-004|Скорректировать операцию|
|CAPA-005|Провести повторную приёмку|

---

# Главная схема

```
        STD
         │
         ▼
        OP
         │
         ▼
      Проход
         │
         ▼
        QA
     ┌───┴────┐
     │        │
     ▼        ▼
 Принято      NC
     │        │
     │      CAPA
     │        │
     └────────┘
         ▼
 Повторная QA
```

## И последнее. 😊

Мне кажется, мы сейчас впервые получили **не "документ по качеству"**, а **организационный механизм**.

Эта схема обладает хорошим инженерным свойством: она **масштабируется без изменения архитектуры**.

Через год вместо пяти операций может быть пятьдесят. Вместо пяти критериев QA — двести. Вместо пяти стандартов — целая библиотека. Но сама конструкция останется прежней:

> **STD → OP → QA → NC → CAPA**

Это признак хорошей архитектуры: не нужно перестраивать фундамент, чтобы надстроить новые этажи.

💥 Я бы уже присвоил этому документу официальный статус:

**STD-000 «Система качества SHIFT»** — **Core / Литера O**.

С него можно начинать собственный «QSB для Завода инженерного знания». 🚢
