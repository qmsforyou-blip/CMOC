# Библиотека организационных сборок

Организационная сборка — это типовое инженерное решение, предназначенное для устранения одного или нескольких организационных разрывов путём развития организационных способностей.

Каждая сборка должна иметь связи:

- Flow
- Gap
- Capability
- Property
- Mechanism
