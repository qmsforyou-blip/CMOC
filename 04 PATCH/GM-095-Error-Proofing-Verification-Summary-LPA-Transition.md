## 1. SOURCE EXTRACTION

### p. 222 — 6.4 Summary; shalls

SOURCE summarizes five obligations for Error Proofing Verification:

1. Error proofing devices shall be verified at least once per day.
2. Error proofing device locations shall be documented.
3. Reaction plans shall exist for device failures, with control of nonconforming product given as an example (Strategy #2).
4. Verification results shall be recorded.
5. Leadership shall review verification results.

These statements summarize requirements already developed in the preceding Error Proofing Verification pages.

### p. 223 — 7.0 Layered Process Audits

SOURCE begins the next section with the heading **7.0 LAYERED PROCESS AUDITS** and the question:

**“Were Leadership Layered Process Audits Performed?”**

This page is a transition into the next source block. It does not provide the LPA method, frequency, roles, checklist or reaction requirements beyond identifying the subject as Leadership Layered Process Audits.

---

## 2. DISTINCTIONS

### D1 — Summary requirement vs. new requirement

**Status: SOURCE-SUPPORTED**

The five “shall” statements on p. 222 function as a summary of the Error Proofing Verification requirements established in the preceding section. They should not automatically be treated as five new distinctions in REG-001 where the underlying distinctions have already been recorded.

### D2 — Error Proofing Verification vs. Layered Process Audits

**Status: CMOC INTERPRETATION / CANDIDATE**

The document changes from section 6.4 Error Proofing Verification Summary to section 7.0 Layered Process Audits. This supports treating LPA as the subject of a subsequent control block, but the two-page fragment does not itself define the conceptual relationship between the mechanisms.

Do not promote this candidate distinction to CANON from pp. 222–223 alone.

### D3 — Audit topic introduction vs. audit method definition

**Status: SOURCE-SUPPORTED**

Page 223 identifies Leadership Layered Process Audits as the next audit topic through a question, but does not yet define how such audits are to be performed.

## 8. CMOC INTERPRETATION

The important result of pp. 222–223 is methodological: **the source closes the Error Proofing Verification block with an explicit “shall” summary and then opens a new control domain, Layered Process Audits.**

The summary on p. 222 confirms five system obligations:

```text
DAILY VERIFICATION
LOCATION DOCUMENTATION
FAILURE REACTION
RESULT RECORDING
LEADERSHIP REVIEW
```

Most of these are already represented by the distinctions extracted from pp. 216–221. Therefore, adding duplicate REG-001 distinctions would reduce the value of the raw distinction journal.

Page 223 should be treated as the beginning of the next source block rather than as sufficient evidence for a complete LPA mechanism.
