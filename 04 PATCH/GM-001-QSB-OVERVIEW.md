## 3. DISTINCTIONS

**DIS-GM-001-01**  
Источник явно разделяет три уровня описания QSB: **Common Principles / Common Methods / Common Processes**.

**DIS-GM-001-02**  
QSB представлена не как один процесс, а как набор **11 стратегий**, каждая из которых имеет собственное содержание и далее раскрывается отдельным разделом.

**DIS-GM-001-03**  
Источник прямо заявляет цель **ONE LANGUAGE GLOBALLY**.

**DIS-GM-001-04**  
Внутри одной стратегии могут объединяться процесс, метод решения проблем и механизм сохранения опыта; например Fast Response включает Fast Response Process, Problem Solving и Lessons Learned.
