# REG-001 PATCH — GM-099 — LPA Scheduling and Tracking pp. 230–231

## Извещение на изменение

**Извещение на изменение — REG-001 — 0121+300826**

### Источник
GM Quality System Basics Overview Supplier Audit.pdf, pp. 230–231, §7.2.1 Scheduling and tracking.

### Новые различения

**DIS-0534** — Организационные уровни, выполняющие LPA, должны быть определены.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0535** — Частота LPA должна быть определена для каждого организационного уровня.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0536** — На ежедневном уровне аудит выполняет manufacturing supervisor.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0537** — На еженедельном уровне manufacturing area manager проводит аудит и проверяет выполнение supervisor verification.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0538** — Ежемесячно site leadership проводит LPA и рассматривает результаты аудитов и corrective actions.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0539** — В примере LPA показаны четыре организационных слоя: Supervisor / Team Leader, Manager / Engineers, Plant Manager, Executive Managers / Directors.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0540** — В примере для Supervisor / Team Leader установлена ежедневная частота.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0541** — В примере для Manager / Engineers установлена частота 1 раз в неделю.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0542** — В примере для Plant Manager установлена частота 1 раз в месяц.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0543** — В примере для Executive Managers / Directors установлена частота не реже одного раза в квартал.  
**Статус:** SOURCE-SUPPORTED; пример.

### Важное ограничение

Структура и частоты на p.231 явно обозначены как **Example**. Поэтому они не регистрируются как универсальные требования организации.

### Кандидаты CMOC

**CAND-0546** — Частота контроля привязывается к организационному уровню.  

**CAND-0547** — Более высокий уровень может проверять не только процесс, но и факт выполнения контроля нижнего уровня.  

**CAND-0548** — Многоуровневая система допускает дифференцированную частоту контроля по уровням управления; конкретная конфигурация является параметром системы.
