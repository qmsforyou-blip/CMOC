# STD-008-v0.5 — Delta after relation-dependent test

## Основание

STD-008 v0.4 + AUTOMATED-RUN-002 M07 multi-object test + M08 relation-dependent test, SOURCE SRC-002.

## 1. Relation-dependent ветвь испытана

Проверена ветвь:

`PASSPORTS + SOURCE-SUPPORTED MULTI-OBJECT CONTEXT → RELATION CANDIDATES → M08 DECISION`

M07 создал 30 relation candidates при наличии обоих endpoint'ов и явно поддержанного направления.

M08 обработал все 30 relation candidates:

- 30 решений;
- 30 PROVISIONAL;
- 0 NEEDS_EVIDENCE;
- 0 CANONICAL.

## 2. Нормативное уточнение M07

Изолированный Passport не является достаточным основанием для установления Relation, если второй endpoint и направление не следуют из самого Passport.

M07 должен получать либо source-supported multi-object context, либо эквивалентный пакет оснований, содержащий оба endpoint'а и основание направления.

Если условия не выполнены, M07 обязан вернуть явный отрицательный результат, например `NO_RELATION`, с причиной.

## 3. Нормативное уточнение M08

Relation Candidate может использоваться как evidence для source-bound decision.

Но:

`RELATION CANDIDATE ≠ ESTABLISHED RELATION`

и

`SOURCE-SUPPORTED RELATION ≠ CMOC CANONICAL RELATION`.

Один SOURCE не получает права автоматически присвоить CANONICAL.

## 4. Статус доказательства

После relation-dependent test автоматический конвейер имеет два проверенных режима M07:

1. isolated passport mode → explicit NO_RELATION;
2. multi-object context mode → relation candidates.

Оба режима являются контролируемыми результатами.
