## 1. SOURCE

SOURCE определяет **Work Element** следующим образом:

> A work element is a logical grouping of actions that advances work to its successful completion.

SOURCE далее указывает:

> Elements are the basic building blocks of SW.

И объясняет их применение в обучении: элементы используются для того, чтобы обучать работе через управляемые части (manageable chunks).

Для **Work Sequence** SOURCE даёт определение:

> Agreed upon order in which work is done to maximize safety, quality, and efficiency.

Таким образом, SOURCE различает две конструкции:

```text
WORK ELEMENT
→ logical grouping of actions
→ advances work to successful completion

WORK SEQUENCE
→ agreed-upon order of work
→ safety + quality + efficiency
```

На следующей странице SOURCE показывает пример разбиения работы **Changing a light bulb** на семь Work Elements. Каждый элемент представлен отдельным блоком на временной шкале.

## 3. DISTINCTIONS — РАЗЛИЧЕНИЯ

### Work Element ≠ Action

SOURCE определяет Work Element как **logical grouping of actions**.

Следовательно, элемент работы — это не обязательно одно действие. Это логически сгруппированная совокупность действий.

**SOURCE-SUPPORTED**

### Work Element ≠ Work Sequence

**Work Element** отвечает на вопрос:

> из каких логически сгруппированных частей состоит работа?

**Work Sequence** отвечает на вопрос:

> в каком согласованном порядке эти части выполняются?

Это различение непосредственно поддерживается двумя определениями SOURCE.

**SOURCE-SUPPORTED**

### Sequence ≠ Time

SOURCE определяет Sequence через **order**, а на примере Work Elements отдельно показывает временную ось.

Следовательно:

```text
SEQUENCE
→ ORDER

TIME
→ TEMPORAL CHARACTERISTIC
```

Не смешиваем.

**SOURCE-SUPPORTED / CMOC INTERPRETATION**

### Work Element ≠ Standardized Work

SOURCE прямо называет элементы **basic building blocks of SW**.

То есть Work Element является составной частью Standardized Work, а не синонимом всей конструкции.

**SOURCE-SUPPORTED**

**CANDIDATE / SINGLE-SOURCE**

## 7. CAPABILITY — СПОСОБНОСТИ

SOURCE поддерживает следующие способности:

- разбивать работу на логически сгруппированные Work Elements;
- представлять работу через управляемые части;
- использовать Work Elements как базовые строительные блоки Standardized Work;
- задавать согласованный порядок выполнения работы;
- использовать Work Sequence как основу для максимизации safety, quality и efficiency;
- использовать элементы работы в обучении.

**SOURCE-SUPPORTED / CANDIDATE**

## 8. ВИЗУАЛЬНЫЙ ПРИМЕР SOURCE — CHANGING A LIGHT BULB

SOURCE показывает работу **Changing a light bulb**, разбитую на семь элементов:

1. **Position ladder in climb position** — расположить лестницу в положение для подъёма.
2. **Remove light cover** — снять защитный кожух светильника.
3. **Loosen old bulb and place on ladder** — ослабить старую лампу и положить её на лестницу.
4. **Get new bulb & Remove plastic from new bulb** — взять новую лампу и снять с неё пластик.
5. **Tighten new bulb into light** — закрепить новую лампу в светильнике.
6. **Position Cover and Tighten** — установить и закрепить кожух.
7. **Return Ladder to Position** — вернуть лестницу в исходное положение.

На графике элементы располагаются последовательно по вертикальной оси **Time**, а горизонтальная ось обозначена **Operator**.

Это визуальное представление SOURCE, а не наша реконструкция.

## 9. ВАЖНОЕ РАЗЛИЧЕНИЕ В ПРИМЕРЕ

SOURCE показывает одновременно:

```text
ELEMENT 1
ELEMENT 2
ELEMENT 3
...
ELEMENT 7
```

и их расположение относительно **Time**.

Следовательно, пример демонстрирует совместное представление:

```text
WORK ELEMENT
+
SEQUENCE
+
TIME
```

Но SOURCE на этой странице **не задаёт математического правила расчёта времени** и не утверждает, что каждый элемент должен иметь одинаковую длительность.

**SOURCE-SUPPORTED / NO EXTRA INFERENCE**

## 10. CMOC INTERPRETATION — КАНДИДАТЫ

### Work as Decomposable Object

> Работа может быть представлена через логически сгруппированные элементы, каждый из которых продвигает работу к успешному завершению.

**CMOC INTERPRETATION / CANDIDATE**

### Standardized Work as Structured Composition

```text
STANDARDIZED WORK
↓
WORK ELEMENTS
↓
WORK SEQUENCE
↓
TIME
```

Это реконструкция на основании нескольких элементов SOURCE; не объявлять её Canon.

**CMOC INTERPRETATION / CANDIDATE**

### Elementization Enables Training

SOURCE прямо связывает Work Elements с обучением через manageable chunks.

Поэтому:

```text
WORK
↓
ELEMENTIZATION
↓
MANAGEABLE CHUNKS
↓
TRAINING
```

**SOURCE-SUPPORTED / CANDIDATE**

## 12. СВЯЗЬ С GM-083

GM-083 показала SOS как структурированный носитель Standardized Work:

```text
SOS
→ WORK ELEMENTS
→ ELEMENT TIMES
→ WORK FLOW / SEQUENCE
```

GM-084 теперь раскрывает два центральных объекта этой структуры:

```text
WORK ELEMENT
→ WHAT THE WORK IS STRUCTURED INTO

WORK SEQUENCE
→ IN WHAT AGREED ORDER IT IS DONE
```

Поэтому:

```text
GM-083
SOS = CONTAINER / REPRESENTATION

GM-084
ELEMENT + SEQUENCE = STRUCTURAL CONTENT
```

**CMOC INTERPRETATION / CANDIDATE**

## 14. НЕ ВНОСИМ В CORE

На основании одного SOURCE пока не создаём отдельные Canonical Entities для:

- Work Element;
- Work Sequence;
- Elementization;
- Sequence Definition.
