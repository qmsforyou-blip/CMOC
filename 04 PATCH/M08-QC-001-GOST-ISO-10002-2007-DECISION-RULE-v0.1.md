# M08 QC-001 — GOST ISO 10002-2007 — DECISION RULE v0.1

Дата: 18-09-2026

## Назначение

Проверка DECISION RULE v0.1 на полном наборе 40 паспортных объектов Run B без изменения исторических Run A и Run B.

## Результат

Input: 40 PAS-B  
Decisions: 40  
PROVISIONAL: 38  
NEEDS_EVIDENCE: 2  
CANONICAL: 0  
Missing decisions: 0  
NEEDS_EVIDENCE without EVIDENCE_GAP: 0

### NEEDS_EVIDENCE

- **PAS-B-009 — Терминологическая модель процесса жалоб / CONCEPT_MODEL**  
  EVIDENCE_GAP: источник определяет специальные термины, но не устанавливает явно, что их совокупность образует один самостоятельный объект класса CONCEPT_MODEL, а не набор терминологических объектов и отношений. Требуется дополнительное основание границы и типа.

- **PAS-B-012 — Цель, политика и процесс / MANAGEMENT_CONCEPT**  
  EVIDENCE_GAP: кандидат объединяет три понятийных уровня — цель, политика и процесс. Требуется дополнительное основание, что это один объект, а не три объекта и связи между ними.

### Переведены в PROVISIONAL по новому правилу

- **PAS-B-002 — SOURCE_IDENTITY:** source-bound идентичность источника прямо поддержана извлечением; универсальность метаданных не является условием текущего M08.
- **PAS-B-019 — ROLE:** роль представителя руководства прямо задана источником отдельным набором ответственности и полномочий; универсальность роли относится к последующей CMOC-канонизации.
- **PAS-B-001 — GUIDANCE:** сама классификация GUIDANCE не является доказательным дефицитом.

## Контрольные инварианты

1. 40/40 входов получили решение.
2. Каждый NEEDS_EVIDENCE содержит конкретный EVIDENCE_GAP.
3. Известный unresolved gap не скрыт под PROVISIONAL.
4. Правило основано на последовательности Evidence → Boundary → Type, а не на имени или порядке объекта.
5. CANONICAL не присваивается в source-bound проходе.
6. Исторические Run A и Run B не изменяются.

## Вердикт

**QC-001 PASS по полноте и формальной применимости правила.**

Правило устраняет две причины, которые ранее ошибочно могли повышать неопределённость: требование универсализации ROLE и сам факт принадлежности объекта к GUIDANCE/SOURCE_IDENTITY. Одновременно оно сохраняет реальные boundary/type gaps для 009 и 012.

Этот QC не является переписыванием исторического M08 Run B; это новый контрольный артефакт, фиксирующий результат применения нового правила к тем же входным PAS-B.
