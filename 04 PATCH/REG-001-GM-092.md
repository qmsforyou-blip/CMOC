## PATCH REG-001

| ID | Type | Различение | Источник | Status |
|---|---|---|---|---|
| **DIS-0487** | NEW | Следует различать **наличие устройства защиты от ошибок** и **проверку его работоспособности**. Сам факт установки устройства не является подтверждением его способности выполнять защитную функцию. | GM QSB 6.2 | |
| **DIS-0488** | NEW | Следует различать **минимальную периодичность проверки** и **фактическую периодичность, выбранную для процесса**. Минимум составляет один раз в день, а частота определяется с учётом условий процесса. | GM QSB 6.2 | |
| **DIS-0489** | NEW | Следует различать **калибровку / mastering средства измерения** и **проверку error proofing device**. Проверка устройства заключается в подтверждении его реакции на известные годные и дефектные детали. | GM QSB 6.2 | |
| **DIS-0490** | NEW | Следует различать **error proofing** и **error detection**: первое не допускает изготовление/сборку несоответствующей продукции, второе не допускает её прохождение или принятие. | GM QSB 6.2 | |
| **DIS-0491** | NEW | Следует различать **механизм защиты** и **результат его проверки**. Управляемость требует подтверждать корректную работу устройства, а не предполагать её. | GM QSB 6.2 | |
| **DIS-0492** | NEW | Следует различать **идентичность устройства** и **его физическое расположение** как управляемую информацию: SOURCE требует master document с идентификационным номером и местом расположения. | GM QSB 6.2 | |
| **DIS-0493** | NEW | Следует различать **саму проверку** и **определение объекта проверки**. Должны быть идентифицированы Good/Bad masters и дефект, который ими проверяется. | GM QSB 6.2 | |
| **DIS-0494** | NEW | Следует различать **использование master** и **подтверждённый статус самого master**. SOURCE требует определить требования к сертификации всех masters. | GM QSB 6.2 | |
| **DIS-0495** | NEW | Следует различать **частоту проверки как произвольный интервал** и **частоту как функцию характеристик процесса**: учитываются размер партии, история процесса, его устойчивость и простота локализации подозрительной продукции. | GM QSB 6.2 | |
| **DIS-0496** | NEW | Следует различать **проверку только при запуске** и **проверку в ходе производства**. Предпочтительный метод SOURCE — выполнение проверки членом команды/лидером при запуске и в течение смены. | GM QSB 6.2 | |
