# GM-086 — Display of Standardized Work / Operator Instructions / JES

**Дата:** 30-08-2026
**Источник:** GM Quality System Basics Overview Supplier Audit.pdf, pp. 166–171
**Статус:** CANDIDATE / SINGLE-SOURCE

## SOURCE

SOURCE устанавливает, что **Standardized Work shall be displayed at or near each operation**.

Назначенные функции такого отображения включают:
- выполнение операций одинаковым способом;
- снижение риска пропуска компонентов;
- обозначение quality checks и их частоты;
- облегчение выявления улучшений процесса;
- упрощение и унификацию обучения;
- напоминание правильной последовательности;
- предупреждение оператора о safety concerns;
- подтверждение выполнения approved process;
- визуальную поддержку руководства при проверке выполнения утверждённой операции;
- разделение machine work, operator hand work и walk time;
- включение времени, выделенного на quality checks.

SOURCE формулирует: **Standardized Work provides a basis for effective Operator Instructions.**

## Документная архитектура

4.4 Standardized Work разделяется на:

### 4.4.1 Standard Operation
- Major Steps
- How long should it take?
- SOS — Standard Operation Sheet

### 4.4.2 Operator Instructions
- Detailed Steps
- What / How / Why
- JES — Job Element Sheet

SOURCE показывает связь Standard Operation Sheets с наборами JES по элементам последовательности.

## Job Element Sheet

SOURCE определяет JES как user-friendly document, содержащий подробную информацию о конкретном элементе работы для обеспечения успешного выполнения этого элемента.

Назначение JES по SOURCE:
- подробная информация для обучения новых Team Members;
- мост между engineering information и shop floor knowledge;
- письменная история элемента;
- база для auditing, problem solving, continuous improvement, rebalancing of work и documentation transfer.

## Пример JES

Визуальный пример показывает структуру:

`Major Step (What) + Key Point (How) + Reason (Why)`

То есть для конкретного Work Element документирует:
- что делать;
- ключевую точку выполнения / как делать;
- почему это важно.

## Область применения Operator Instructions

SOURCE указывает не только manufacturing and assembly, inspection/data collection, pack out и laboratory, но и часто упускаемые виды деятельности: offline rework and containment, setup/change-over, prototype and engineering activities, process labeling, material handling, shipping/receiving, maintenance/repair и office.

## Distinctions

`WORK ELEMENT ≠ JOB ELEMENT SHEET`

Work Element — единица работы. JES — документ с подробной информацией об этой конкретной единице.

`STANDARDIZED WORK ≠ OPERATOR INSTRUCTIONS`

SOURCE связывает их как основу и производное представление, а не как одно понятие.

## CMOC Interpretation

Standardized Work и Operator Instructions образуют связанные, но различные уровни представления работы: первый задаёт стандартизированную операцию, второй раскрывает конкретные элементы для непосредственного выполнения, обучения и последующего использования в аудите и улучшении.
