# REG-001 PATCH — GM-100 — LPA Station Coverage and Leadership Scheduling pp. 232–233

## Извещение на изменение

**Извещение на изменение — REG-001 — 0122+300826**

### Источник
GM Quality System Basics Overview Supplier Audit.pdf, pp. 232–233, §7.2.1 Scheduling and tracking.

### Новые различения

**DIS-0544** — Охват LPA может контролироваться на уровне отдельных рабочих мест (stations) внутри рабочей зоны.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0545** — График/таблица LPA может использоваться для обеспечения того, чтобы каждое рабочее место оценивалось не реже одного раза в месяц.  
**Статус:** SOURCE-SUPPORTED; пример реализации.

**DIS-0546** — Все аудиторы используют график для определения рабочих мест, которые ещё не были проверены.  
**Статус:** SOURCE-SUPPORTED; пример реализации.

**DIS-0547** — Для выбранного для аудита рабочего места фиксируются имя аудитора, дата и смена.  
**Статус:** SOURCE-SUPPORTED; пример реализации.

**DIS-0548** — Цель примера — проверить каждое рабочее место, где присутствует член команды, один раз в месяц.  
**Статус:** SOURCE-SUPPORTED; пример реализации.

**DIS-0549** — Планирование аудитов руководящим персоналом необходимо для обеспечения взаимодействия всех зон производственного участка с управленческой командой.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0550** — Пример расписания руководящих аудитов одновременно отражает требуемую частоту аудита конкретным руководителем и статус соответствующего взаимодействия.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0551** — В расписании может фиксироваться не только плановая частота, но и факт выполнения запланированного аудита/взаимодействия.  
**Статус:** SOURCE-SUPPORTED; пример.

### Важное ограничение

Страницы 232–233 используют конкретные графики и расписания как **Examples**. Поэтому бумажный формат таблицы, конкретная схема отображения и конкретные уровни руководства не регистрируются как универсальные требования.

### Кандидаты CMOC

**CAND-0549** — Охват контроля может быть объектом отдельного управления: система должна позволять видеть, какие объекты контроля уже проверены, а какие ещё нет.

**CAND-0550** — Аудит должен оставлять минимальный след исполнения, позволяющий связать проверку с исполнителем, временем и сменой.

**CAND-0551** — Расписание аудитов является механизмом управления не только частотой, но и полнотой охвата.

**CAND-0552** — Взаимодействие управленческих уровней с производственным участком может быть предметом планирования и контроля исполнения.

**CAND-0553** — Статус выполнения запланированного контрольного взаимодействия является самостоятельным объектом контроля.

## Ключевое различение

Источник развивает предыдущую связку «уровень → частота → ответственность» в сторону фактического покрытия:

**ЧАСТОТА → ОХВАТ ОБЪЕКТОВ → ЗАПИСЬ ИСПОЛНЕНИЯ → СТАТУС ВЫПОЛНЕНИЯ**

Для руководящих уровней дополнительно:

**ПЛАН АУДИТОВ → ВЗАИМОДЕЙСТВИЕ С ПРОИЗВОДСТВОМ → СТАТУС ВЗАИМОДЕЙСТВИЯ**
