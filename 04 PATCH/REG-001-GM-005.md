## PATCH REG-001

| ID | Type | Различение | Источник | Status |
|---|---|---|---|---|
| **DIS-0479** | NEW | Следует различать **обучение** и **сертификацию**. Знание операции ещё не означает подтверждённую способность выполнять её самостоятельно. | GM QSB 5.4–5.5 | |
| **DIS-0480** | NEW | Следует различать **наличие инструкции** и **подготовленность исполнителя**. Документ не заменяет обучение. | GM QSB 5.4–5.5 | |
| **DIS-0481** | NEW | Следует различать **обучение работника** и **ведение записи об обучении**. Управляемость требует сохранения истории подготовки персонала. | GM QSB 5.4–5.5 | |
| **DIS-0482** | NEW | Следует различать **квалифицированного работника** и **сертифицированного инструктора**. Выполнять работу и обучать работе — разные способности. | GM QSB 5.4–5.5 | |
| **DIS-0483** | NEW | Следует различать **одноразовое обучение** и **поддержание компетентности**. Компетенция требует повторной подготовки через определённые интервалы. | GM QSB 5.4–5.5 | |
| **DIS-0484** | NEW | Следует различать **наличие устройства защиты от ошибок** и **подтверждение его работоспособности**. Само существование устройства не гарантирует защиту процесса. | GM QSB 6.0–6.1 | |
| **DIS-0485** | NEW | Следует различать **калибровку средства измерения** и **проверку устройства защиты от ошибок**. Проверяется не точность измерения, а способность обнаруживать или предотвращать дефект. | GM QSB 6.0–6.1 | |
| **DIS-0486** | NEW | Следует различать **исправное устройство** и **доказательство его исправности**. Управляемость строится на результатах проверки, а не на предположении. | GM QSB 6.0–6.1 | |
