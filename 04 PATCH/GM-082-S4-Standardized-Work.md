# GM-082 — S-4: STANDARDIZE / STANDARDIZED WORK

**Дата:** 30-08-2026
**Статус:** SOURCE-SUPPORTED / SINGLE-SOURCE
**Извещение на изменение:** 0191+300826

## 1. SOURCE

Раздел 4.4 — STANDARDIZED WORK.

### 4.4.1 — Standard Operation
- Major Steps
- How long should it take?
- SOS

### 4.4.2 — Operator Instructions
- Detailed Steps
- What, How, and Why
- JES

SOURCE определяет Standardized Work как документ рабочих функций, выполняемых в повторяемой последовательности, которая согласована, разработана, выполняется и поддерживается функциональной организацией.

Purpose: установить повторяемый, предсказуемый baseline для continuous improvement и вовлекать оператора как в первоначальные, так и в последующие улучшения для достижения высоких уровней safety, quality and productivity.

## 3. DISTINCTIONS — РАЗЛИЧЕНИЯ

### Standardized Work ≠ Operator Instructions

Operator Instructions являются отдельным элементом 4.4.2 внутри общей конструкции Standardized Work.

### Major Steps ≠ Detailed Steps

Standard Operation работает с Major Steps; Operator Instructions — с Detailed Steps.

### Major Steps / Time ≠ What / How / Why

SOURCE относит Major Steps и вопрос о длительности к Standard Operation, а What / How / Why — к Operator Instructions.

### Standardized Work ≠ Final State

SOURCE называет Standardized Work repeatable, predictable baseline **for continuous improvement**. Следовательно, стандарт выступает опорой для улучшения, а не объявляется неизменяемым конечным состоянием.

## 4. EXTRACTION — ИЗВЛЕЧЕНИЕ

Внутри Standardized Work SOURCE выделяет:

```text
STANDARD OPERATION

→ How long should it take?

```

```text

→ JES
```

## 5. MECHANISM — МЕХАНИЗМ

### Standardized Work as Repeatable Sequence

**CANDIDATE / SINGLE-SOURCE**

Рабочие функции представляются как повторяемая последовательность, согласованная, разработанная, выполняемая и поддерживаемая функциональной организацией.

### Standard Operation + Operator Instructions

**CANDIDATE / SINGLE-SOURCE**

Структура 4.4 разделяет представление работы на уровень основных шагов и времени операции и уровень детальных инструкций What / How / Why.

## 6. CAPABILITY — СПОСОБНОСТИ

- создавать повторяемую последовательность выполнения рабочих функций;
- формировать предсказуемый baseline;
- представлять работу на уровне Major Steps и Detailed Steps;
- вовлекать оператора в первоначальное и последующее улучшение.

**Статус:** CANDIDATE / SINGLE-SOURCE.

## 7. MACHINE — МАШИНКА

### Standardized Work Baseline

**CANDIDATE / SINGLE-SOURCE**

**CANDIDATE / SINGLE-SOURCE**

## 9. CMOC INTERPRETATION

### Standard as Improvement Baseline

**CANDIDATE**

Стандарт одновременно фиксирует воспроизводимое представление текущей работы и создаёт baseline, относительно которого возможно последующее улучшение.

### Standard Exists ≠ Standard Institutionalized

**CANDIDATE**

SOURCE использует четыре организационных состояния/действия: agreed to, developed, followed, maintained. Наличие документа само по себе не следует отождествлять с поддерживаемым организацией действующим стандартом.

## 10. STATUS

- Standard Exists ≠ Standard Institutionalized — **CMOC INTERPRETATION / CANDIDATE**
