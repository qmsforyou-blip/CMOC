# GM-085 — Work Elements Example / Element Time

**Дата:** 30-08-2026
**Источник:** GM Quality System Basics Overview Supplier Audit.pdf, pp. 154–159
**Статус:** CANDIDATE / SINGLE-SOURCE

## SOURCE

SOURCE задаёт факторы, которые следует учитывать при формировании Work Elements:
- Geographic build location — географическое расположение сборки;
- Product grouping — группирование продукта;
- Time required to complete the element — время выполнения элемента.

SOURCE отдельно устанавливает: **Walking is not an element**, и обычно не включается в element sheets.

SOURCE также предупреждает не переносить автоматически группировки из существующего engineering Standardized Work: работу следует разбивать с использованием здравого смысла и с учётом того, как работа фактически выполняется.

## Element Time

Element Time — время, необходимое для выполнения элемента.

SOURCE даёт ориентир: размер элемента может составлять примерно 10% от job ATT. Это именно **rough guideline**, а не жёсткий норматив.

## Takt Time / Actual Takt Time

Takt Time определяется как максимальное доступное время на производство продукта или услуги, основанное на customer demand.

Формула SOURCE:

`TT = Production Time Available Per Period / Customer Demand Per Period`

Actual Takt Time (ATT) — плановое время, доступное для производства после учёта системных потерь.

`ATT = (1 − System Losses %) × Takt Time`

## Визуальный пример

SOURCE показывает изменение Customer Takt Time с 60 до 20 секунд и соответствующее распределение трёх Work Elements по трём людям: каждый элемент занимает 20 секунд.

Это SOURCE-SUPPORTED BY EXAMPLE; не превращаем пример в универсальный закон.

## CMOC INTERPRETATION

Work Element является формируемым объектом: его структура зависит не только от содержания действий, но также от места, группирования продукта и временного контекста.

**CANDIDATE:** Work Elementization может выступать механизмом распределения работы относительно временного ограничения Takt Time.

## Важное различение

`OPERATOR MOVEMENT ≠ WORK ELEMENT`

SOURCE прямо исключает Walking из Work Elements.
