# REG-001 PATCH — GM-101 — LPA High-Risk Audit Items pp. 234–235

## Извещение на изменение

**Извещение на изменение — REG-001 — 0123+300826**

### Источник
GM Quality System Basics Overview Supplier Audit.pdf, pp. 234–235, §7.2.2 Development of high risk items for auditing.

### Новые различения

**DIS-0552** — Высокорисковые элементы должны быть идентифицированы и включены в аудит.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0553** — Высокорисковые элементы организуются в три основные секции: Work Station, Quality Focused и Manufacturing System.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0554** — Work Station представляет собой перечень проверок, применимых ко всем рабочим местам.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0555** — Quality Focused содержит проверки, специфичные для операций и разрабатываемые предприятием на основе quality feedback, process knowledge и problem solving.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0556** — Manufacturing System содержит системные проверки, сфокусированные на соответствии производственным операциям предприятия.  
**Статус:** SOURCE-SUPPORTED.

**DIS-0557** — В качестве Work Station issues могут проверяться соблюдение правил безопасности и использование PPE.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0558** — В качестве Work Station issues могут проверяться наличие и использование надлежащих инструментов, gauges и материалов.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0559** — В качестве Work Station issues могут проверяться понимание и соблюдение стандартизированной работы и стандартов качества.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0560** — В качестве Work Station issues может проверяться работоспособность системы Andon.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0561** — В качестве Work Station issues может проверяться поддержание стандартов Workplace Organization и Visual Management.  
**Статус:** SOURCE-SUPPORTED; пример.

**DIS-0562** — В качестве Work Station issues может проверяться соответствие Material Processes уровням FIFO / Min.-Max.  
**Статус:** SOURCE-SUPPORTED; пример.

### Важное ограничение

Шесть конкретных Work Station issues на p.235 представлены как **Examples**. Поэтому они не регистрируются как универсальный обязательный набор проверок для каждой организации.

### Кандидаты CMOC

**CAND-0554** — Высокий риск переводится в конкретный объект содержания аудита — проверяемый audit item.

**CAND-0555** — Содержание аудита может структурироваться по области контроля: рабочее место, специфическая для качества операционная проблематика, производственная система.

**CAND-0556** — Аудитный контент может формироваться из организационного опыта: quality feedback + process knowledge + problem solving.

**CAND-0557** — Один Work Station audit может одновременно охватывать несколько измерений контроля: безопасность, ресурсы, стандартизированную работу, Andon, визуальное управление и материальный поток.

**CAND-0558** — Риск становится операционно управляемым, когда выражен как наблюдаемый check непосредственно в месте выполнения операции.

## Ключевое различение

Источник переводит риск из уровня общей оценки в содержание конкретной проверки:

**ВЫСОКИЙ РИСК → AUDIT ITEM → ПРОВЕРКА В ОПЕРАЦИИ**

и задаёт архитектуру содержания:

**WORK STATION | QUALITY FOCUSED | MANUFACTURING SYSTEM**

Особенно существенно:

**QUALITY FEEDBACK + PROCESS KNOWLEDGE + PROBLEM SOLVING → QUALITY-FOCUSED CHECKS**
