# GM-096 — Independent Source Cross-Check: PPCR / PTR

**Извещение на изменение:** 0137+170926

## 1. Цель

Проверить первые два GM-096 Machine-кандидата по независимым источникам
и определить, усиливается ли их bounded identity за пределами исходного
GM QSB 2009.

## 2. PPCR — Plant Process Change Control

### Independent evidence

GM BIQS training material reproduces Process Change Control requirements:
plant process changes are documented through a plant process change form;
internal/external change forms are controlled through Document Control; the
procedure covers planned and emergency changes; PPCR maintains records of
changes impacting final product and tracks system changes; key stakeholders
are made aware and participate in controlling out-of-standard conditions.

Independent/adjacent GM BIQS audit material also describes a cross-functional
process change approval system and validation of plant processes relative to
changes in Design, Man, Machine, Material, Method and Environment.

### Cross-check result

The independent GM material confirms the same bounded construction:

`change identification → cross-functional review → approval → controlled implementation → record / traceability`

It therefore strengthens PPCR as a reusable change-control Machine rather
than a terminology-specific artifact of the 2009 QSB source.

### Status

`MULTI-SOURCE CONFIRMED / STRONG-CANDIDATE / NON-CANON`

This is confirmation, not canonization.

## 3. PTR — Production Trial Run

### Independent evidence

Later GM Managing Change training material describes PTR as a limited,
controlled and contained production tryout used to evaluate a change before
full production implementation. It requires a written procedure / flowchart
and Communication Form documenting approvals and results.

Additional non-GM manufacturing guidance describes production-trial runs as
controlled production evaluations intended to establish process capability,
production readiness and risk reduction. A Fiat Powertrain procedure defines
PTR as evaluation of a modification using definitive production means before
permanent implementation. Veoneer supplier guidance likewise uses production
trial runs to demonstrate process capability and reduce production/process risk.

### Boundary test

The independent sources confirm that a production trial is a recognizable
bounded construction, but its exact purpose and relation to validation vary
by organization. GM's distinction that PTR is not product validation remains
source-specific and should not be generalized to every PTR implementation.

### Cross-check result

`decision / request → controlled production trial → evidence / evaluation → implementation decision`

The construction is independently reproducible.

### Status

`MULTI-SOURCE CONFIRMED / SPECIALIZED-CANDIDATE / NON-CANON`

## 5. Verdict

**PPCR and PTR both pass the first independent-source cross-check.**

PPCR shows strong cross-source stability as a change-control Machine.
PTR shows cross-source stability as a specialized production-trial Machine,
while retaining the limitation that validation relationships are context-
dependent.
