# REPEATABILITY-RUN-001-GOST-M07-A-B-SEMANTIC-COMPARISON-CORRECTED

Дата: 17-09-2026

## Назначение

Исправленная семантическая сверка M07 (RELATIONS) между Run A и Run B
для источника:

`SRC-GOST-ISO-10002-2007-001`

Цель — отличить реальное семантическое расхождение Relations от вариации
отображаемого наименования объектов.

## Результат

После нормализации идентичности концов связи:

- MATCH: 25
- VARIANT: 0
- DIVERGENCE: 0

Итого: **25/25 семантически совпадают.**

## Правило сравнения

Relation сравнивается не по буквальному совпадению названий объектов,
а по тройке:

`SOURCE_OBJECT_ID → RELATION_TYPE → TARGET_OBJECT_ID`

Отображаемое наименование объекта не является самостоятельным критерием
семантического расхождения.

Следовательно:

`Surface naming variation ≠ semantic variation`

Во всех восьми случаях изменилось отображение имени объекта/уточнение

соединяемых объектов.

## Методологическое следствие

Для повторяемости M07 необходимо сравнивать:

1. идентичность source object;
2. тип relation;
3. идентичность target object.

Текстовые labels следует использовать как представление объекта, а не
как его идентификатор.

### Нормативная формулировка

> **M07 Repeatability Rule:** при сравнении Relations между повторными
> проходами семантическое совпадение определяется по идентичности
> объектов-источников и объектов-назначений и типу Relation, а не по
> буквальному совпадению их отображаемых наименований.

## Вывод

Первоначальный результат `17/25 direct semantic match` являлся артефактом
строкового сравнения. После корректной нормализации endpoint identity
результат M07 составляет:

**25 MATCH / 0 VARIANT / 0 DIVERGENCE.**

Таким образом, в пределах данного контролируемого повторного прогона
M07 не выявил содержательного расхождения между Run A и Run B.

Это правило должно быть учтено в QC повторяемости Relations и применено
перед финальной сверкой M08.

## Ограничение

Run B является отдельным аналитическим проходом без передачи ему
результатов Run A как входных данных. Это контролируемый тест
повторяемости, но не статистически независимый эксперимент с другим
исполнителем или другой моделью.
