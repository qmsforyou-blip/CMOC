
# STD-007. Верификация терминологии

## Статус

Проект

---

# Назначение

Настоящий стандарт определяет порядок включения терминов в Канон CMOC.

Цель стандарта — обеспечить полную прослеживаемость происхождения каждого термина.

---

# Основной принцип

Ни один термин не включается в Канон без подтверждения его происхождения.

---

# Источники

Допустимыми источниками являются:

- книги;
- эссе;
- сборки;
- статьи;
- публикации;
- авторские заметки.

Рабочие обсуждения, лабораторные идеи и диалоги не являются основанием для включения термина в Канон.

---

# Для каждого термина фиксируется

- идентификатор;
- наименование;
- первое документированное появление;
- источник;
- контекст появления;
- статус происхождения.

---

# Статусы происхождения

## ✅ CANON

Термин явно присутствует в авторском корпусе.

Подлежит включению в Реестр T.

---

## 🟡 IMPLIED

Понятие присутствует.

Термин требует подтверждения.

---

## 🔵 CMOC

Термин появился в процессе разработки CMOC.

Не является частью Канона.

Подлежит регистрации в отдельном реестре.

---

## ❌ NONE

Термин в авторском корпусе отсутствует.

В Канон не включается.

---

# Порядок проверки

Для каждого термина производится:

1. Поиск первого появления.
2. Проверка контекста.
3. Проверка самостоятельности использования.
4. Присвоение статуса.
5. Регистрация результата.

---

# Запрещается

Запрещается:

- создавать новые канонические термины по аналогии;
- изменять термин без фиксации причины;
- присваивать статус CANON без подтверждения источником.

---

# Результат проверки

После завершения ревизии каждый термин Реестра T имеет:

- подтверждённое происхождение;
- ссылку на первое появление;
- статус происхождения;
- решение о включении в Канон.
