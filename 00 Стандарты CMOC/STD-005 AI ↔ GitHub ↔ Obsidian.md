# STD-005 AI ↔ GitHub ↔ Obsidian

## Назначение

GitHub является общим версионируемым контуром обмена между Obsidian и AI.

## Правила

1. Obsidian — основная рабочая среда инженера.
2. GitHub — версионируемое хранилище и общий источник актуального состояния CMOC.
3. AI читает и анализирует CMOC непосредственно из GitHub.
4. AI может создавать и изменять файлы CMOC в GitHub.
5. Изменения AI фиксируются commit'ом.
6. После изменений в GitHub локальный CMOC синхронизируется через Git pull.
7. Один файл не редактируется одновременно человеком и AI.
8. Содержательные изменения CMOC проходят через Git и сохраняют историю.

## Контур

Obsidian → Git → GitHub ↔ AI

GitHub → Git pull → Obsidian

## Принцип

> GitHub не заменяет Obsidian.
> GitHub связывает инженерную работу человека и AI.
