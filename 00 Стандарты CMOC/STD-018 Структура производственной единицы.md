# STD-018 Структура производственной единицы

## Назначение

Стандарт определяет единую структуру всех производственных единиц Института организационной инженерии.

## Обязательная структура

1. YAML
2. Название
3. Назначение
4. Содержание
5. Связанные объекты
6. История изменений

## Требования

- Все производственные единицы имеют одинаковую структуру.
- Названия разделов являются обязательными.
- YAML располагается первым блоком файла.
- История изменений располагается последним разделом файла.
