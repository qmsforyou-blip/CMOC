# STD-011 Принципы инвентаризации

## Цель

Инвентаризация предназначена для выявления и регистрации типовых компонентов организационного мира.

---

## Правила

1. Инвентаризируется реальность, а не модель.

2. Каждый объект регистрируется один раз.

3. Один объект — один файл.

4. Каждый объект должен принадлежать одному типу.

5. Каждый объект должен иметь уникальный идентификатор.

6. Каждый объект постепенно связывается с другими объектами.

7. Структура объекта развивается, но идентификатор не изменяется.

---

## Главное правило

Сначала обнаружить.

Потом зарегистрировать.

Потом понять.

Потом связать.

Никогда наоборот.
