# STD-REG-001 Происхождение знаний

## Принцип

Любое утверждение CMOC должно быть прослеживаемо до места своего первого появления.

Прослеживаемость является обязательным свойством организационного знания.

---

## Цепочка происхождения

Реальность
→ Наблюдение
→ Источник (SRC)
→ Локатор (LOC)
→ Различение (DIS)
→ Термин (T)
→ Сущность (E)
→ Механизм (M)
→ Конструкция (C)
→ Сборка (A)

---

## Правила

1. Каждый DIS обязан ссылаться на один LOC.

2. Каждый LOC принадлежит одному SRC.

3. LOC не изменяется при развитии онтологии.

4. Онтология развивается, происхождение знания сохраняется.

5. Потеря происхождения считается дефектом организационного знания.
