
## Основной принцип

Каждый проход добавляет только один новый смысловой слой модели.

## Следствия

- Один проход — одна цель.
- Не смешивать разные виды анализа.
- Каждый следующий проход использует результаты предыдущего.
- Модель развивается послойно.


> Каждый проход имеет одну цель и добавляет только один новый слой модели.
