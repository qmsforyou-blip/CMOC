# Паспорт класса "Проход"

## Назначение

Проход — стандартизированная производственная операция, которая добавляет одну новую характеристику всем экземплярам выбранного реестра.

## Основные свойства

- Выполняется в течение одной смены.
- Изменяет только один аспект Реестра.
- Не создаёт новые сущности без необходимости.
- Завершается только после обработки всех строк Реестра.

## Вход

Реестр.

## Выход

Обогащённый Реестр.

## Критерий завершения

Все строки обработаны.

## Результаты прохода

1. Изменённый Реестр.
2. Производственный отчёт.
3. Новая версия производственной единицы.
4. COM.
