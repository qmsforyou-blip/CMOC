# R-CLASS-001 Паспорт класса Реестр

## Назначение

Реестр предназначен для хранения экземпляров одного класса объектов.

## Основные свойства

- Один реестр хранит экземпляры одного класса.
- Каждая строка является экземпляром объекта.
- Структура строк определяется проходами.
- Реестр является входом и выходом производственных проходов.

## Вход

Экземпляры объектов.

## Выход

Обогащённый реестр экземпляров.

## Критерий готовности

Все экземпляры соответствуют утверждённой структуре.
