# R2.3 — NEW DECISION Evidence Gate

**ID:** R2.3-NEW-DECISION-EVIDENCE-GATE-001  
**Дата:** 22-09-2026  
**Статус:** TEST CONTRACT CANDIDATE  
**Область:** NEW DECISION  
**Основание:** R2 + R2.1 + R2.2 + R1 Evidence

## 1. Цель

Проверить минимальный Evidence Gate для отдельного слоя NEW DECISION.

R2.3 отвечает только на вопрос:

> **Достаточно ли сформирован доказательный пакет, чтобы передать source-bound кандидата в отдельное NEW DECISION?**

R2.3 не принимает решение NEW и не изменяет CMOC.

## 2. Граница

Вход: NEW_DECISION_INPUT

Выход: ELIGIBLE_FOR_NEW_DECISION или NOT_ELIGIBLE.

R2.3 не производит:
- NEW_APPROVED;
- NEW_REJECTED;
- CANONIZATION;
- CMOC WRITE.

## 3. Минимальный NEW_DECISION_INPUT

Концептуально:

```yaml
new_decision_input:
  candidate:
    record_id:
    value:
    object_boundary:

  reconciliation:
    match_result:
    basis:
    cmoc_object_id:

  query_evidence:
    query_scope:
    modes:
      exact:
      alias:
      structural:
    results:

  evidence_state:
  target_object_type:
  traceability:
  decision_context:
```

Это тестовая модель. Действующий production contract не изменяется.

## 4. Evidence Gate

Условие:

```text
ELIGIBLE_FOR_NEW_DECISION =
source_bound_candidate
AND traceability_complete
AND query_scope_sufficient
AND exact_checked
AND alias_checked
AND structural_checked_or_NA
AND no_ambiguity
AND no_unresolved_candidate
AND stable_object_boundary
AND target_object_type_resolved
```

Evidence states:
- TRUE — условие выполнено;
- FALSE — условие не выполнено;
- UNKNOWN — достаточность не установлена;
- NOT_APPLICABLE — допустимо только для реально неприменимого режима.

UNKNOWN не преобразуется в TRUE.

## 5. Test Branches

### R2.3-01 — COMPLETE
Все обязательные evidence states TRUE либо обоснованный NOT_APPLICABLE.
Ожидается: ELIGIBLE_FOR_NEW_DECISION.
NEW_APPROVED = NOT_PERFORMED; CMOC_WRITE = NONE.

### R2.3-02 — INSUFFICIENT SCOPE
query_scope_sufficient = FALSE.
Ожидается: NOT_ELIGIBLE.

### R2.3-03 — UNKNOWN TARGET TYPE
target_object_type_resolved = UNKNOWN.
Ожидается: NOT_ELIGIBLE.
Автоматическое отображение working_class → target_object_type запрещено.

### R2.3-04 — UNRESOLVED CANDIDATE
no_unresolved_candidate = FALSE.
Ожидается: NOT_ELIGIBLE.

### R2.3-05 — AMBIGUOUS
no_ambiguity = FALSE.
Ожидается: NOT_ELIGIBLE.

## 6. Mandatory Invariants

Во всех ветках:
1. CMOC не изменяется.
2. OBJECT INDEX не изменяется.
3. DISCOVERY_RESULT не изменяется.
4. UNKNOWN не считается TRUE.
5. ELIGIBLE_FOR_NEW_DECISION не означает NEW_APPROVED.
6. Новый object_id не создаётся.
7. CMOC WRITE отсутствует.

## 7. Изоляция от production Reconciliation

R2.3 не изменяет reconciliation.py, cmoc_query.py, OBJECT INDEX, DISCOVERY_RESULT или RECONCILIATION-INPUT contract.

Тест работает с изолированным синтетическим NEW_DECISION_INPUT.

Причина:
> сначала проверяется семантика Evidence Gate, затем она может быть подключена к runtime отдельным контрактом.

## 8. Проверяемые различия

NO_MATCH ≠ ELIGIBLE_FOR_NEW_DECISION

ELIGIBLE_FOR_NEW_DECISION ≠ NEW_APPROVED

NEW_APPROVED ≠ CMOC_WRITE
