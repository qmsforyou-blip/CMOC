# ADR-0001

## Название

Связи важнее каталогов.

---

## Контекст

По мере роста CMOC количество объектов увеличивается.

Навигация по папкам перестаёт быть основным способом работы.

---

## Решение

Главной структурой CMOC являются связи между объектами.

Папки используются только для хранения.

---

## Последствия

- проектируется граф знаний;
- Dataview становится основным инструментом навигации;
- Graph используется для анализа модели;
- объекты должны содержать ссылки друг на друга.
