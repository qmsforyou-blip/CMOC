# MetaObject

## Назначение

MetaObject определяет обязательную структуру любого объекта CMOC.

Любой объект CMOC является экземпляром MetaObject.

---

# Обязательные поля

| Поле | Назначение |
|------|------------|
| id | Уникальный идентификатор |
| type | Тип объекта |
| name | Наименование |
| status | Статус зрелости |
| definition | Определение |
| purpose | Назначение |
| links | Связи |
| created | Дата регистрации |
| updated | Последнее изменение |

---

# Правило

Любой объект CMOC должен соответствовать MetaObject.
