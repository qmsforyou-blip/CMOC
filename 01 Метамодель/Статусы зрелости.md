# Статусы зрелости объектов CMOC

| Код | Статус | Описание |
|------|---------|----------|
| L0 | Обнаружен | Объект выявлен |
| L1 | Зарегистрирован | Получил идентификатор |
| L2 | Определён | Имеет определение |
| L3 | Связан | Связан с другими объектами |
| L4 | Проверен | Использован на практике |
| L5 | Канонизирован | Входит в канон CMOC |
